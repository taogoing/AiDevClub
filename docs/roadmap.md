# AIDevClub 总体路线图

构建原则：地基 → 依赖 → 纵向切透。每个阶段独立立项，走「brainstorming → 计划 → 实现」流程。

## 阶段总览

| 阶段 | 名称 | 对应需求章节 | 状态 |
|---|---|---|---|
| P0 | 基础设施骨架 | §15 | ✅ 已完成 |
| P1 | 用户与认证 | §4 | ✅ 已完成 |
| P2 | 技术社区（文章 / 评论 / 互动） | §5 | ⏳ 下一阶段 |
| P3 | AI 资源（Skills Hub + MCP Hub） | §6 / §7 / §8 | 未开始 |
| P4 | 标签 / 搜索 / 排行 + 文件上传 | §10 / §14 | 未开始 |
| P5 | 消息通知 + 举报审核 | §11 / §12 | 未开始 |
| P6 | 平台 MCP Server + 管理后台 | §9 / §13 | 未开始 |
| 前端 | 用户端 + 管理端 | — | 未开始（可与后端并行） |

## 各阶段内容

### P0 基础设施骨架 ✅
可运行服务 + MySQL/Redis 接入 + Docker Compose + 配置 / 日志 / 健康检查 + 统一响应与错误中间件。

### P1 用户与认证 ✅
注册 / 登录 / 登出 / Token 刷新、资料管理、注销账号（软删除）、头像上传、注册登录限流。

### P2 技术社区
文章发布 / 编辑 / 删除（草稿 / 发布、分类、标签、正文图片）、文章浏览（分页 / 筛选 / 搜索 / 排序 / 详情）、两级评论、点赞 / 收藏 / 浏览量、内容举报。

### P3 AI 资源（Skills Hub + MCP Hub）
统一资源模型（名称 / 描述 / 作者 / 仓库 / ZIP / 大小 / 下载量等）、ZIP 上传、审核状态机（草稿 → 待审核 → 已发布 / 已拒绝 / 已下架）、资源浏览 / 下载 / 互动。

### P4 标签 / 搜索 / 排行 + 文件上传
统一标签体系（文章 / Skill / MCP 共用）、组合筛选与搜索、Redis 缓存热门排行、文件上传（头像 / 正文图片 / ZIP）。

### P5 消息通知 + 举报审核
站内通知（评论 / 回复 / 点赞 / 审核结果 / 举报结果 / 公告）、未读计数、举报流转与管理员处置。

### P6 平台 MCP Server + 管理后台
整站 MCP Server（复用领域服务，供 Claude Code 等客户端检索 / 操作）、管理后台（用户 / 内容 / 审核 / 标签 / 举报 / 统计 / 操作日志）。

### 前端
Vue 3 用户端（文章 / 资源浏览与发布）+ 管理端。

## 依赖关系

```text
P0 → P1 → P2 → P3 → P4 → P5 → P6 → 前端
```

- P3 / P4 有部分可并行；前端可随各后端阶段并行推进。
- 每个阶段结束时产出可独立运行、可测试的增量。
