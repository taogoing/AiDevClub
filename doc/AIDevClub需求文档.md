# AIDevClub 需求文档

## 1. 项目背景

AIDevClub 是一个面向开发者和 AI Agent 的公开技术社区，用于集中发布和检索技术文章、Skill 与 MCP Server，解决相关内容分散和查找困难的问题。

开发者可以通过网站发布文章、分享 AI 资源并参与社区互动；AI Agent 可以通过平台提供的 MCP Server 检索内容，并在用户授权后发布和管理内容。

## 2. 项目定位

> AIDevClub 是一个面向开发者和 AI Agent 的技术内容与 AI 资源分享社区。

平台包含三个核心板块：

1. 技术社区：发布和交流技术文章。
2. Skills Hub：发布和分享 Skill。
3. MCP Hub：发布和分享 MCP Server。

平台同时提供整站 MCP Server，让 AI Agent 能够访问和操作平台能力。

## 3. 用户角色

### 3.1 游客

- 浏览公开内容。
- 搜索文章、Skill 和 MCP Server。
- 下载已审核通过的公开资源。
- 查看用户公开主页。

### 3.2 注册用户

- 发布和管理自己的文章及评论。
- 发布和管理自己的 Skill、MCP Server。
- 点赞、收藏、举报内容。
- 接收站内通知。

### 3.3 管理员

- 管理用户、内容、分类和标签。
- 审核 Skill 和 MCP Server。
- 处理举报和违规内容。
- 置顶或下架内容。
- 查看平台数据和操作日志。

## 4. 用户与认证

- 邮箱和密码注册。
- 邮箱登录。
- Access Token 与 Refresh Token 认证。
- 退出登录。
- 修改昵称、头像、个人简介和密码。
- 查看用户公开主页及其公开内容。
- 用户状态管理：正常、禁言、禁止发布、封禁、注销。
- 注册、登录接口限流。

## 5. 技术社区

### 5.1 文章管理

- 发布、编辑和删除自己的内容。
- 发布文章的页面可以参考一些公开社区的，可以直接复用或者参考现有的仓库，减小开发难度。
- 上传正文图片。
- 选择分类和标签。
- 保存草稿和正式发布。
- 管理员置顶、隐藏或删除内容。
- 内容采用软删除。

### 5.2 文章浏览

- 分页列表。
- 分类和标签筛选。
- 关键词搜索。
- 最新、热门和置顶排序。
- 内容详情。
- 作者公开信息。
- 浏览、点赞、收藏和评论数量。

### 5.3 评论与互动

- 发布评论和回复。
- 支持两级评论结构。
- 删除自己的评论。
- 内容作者管理自己内容下的评论。
- 管理员处理违规评论。
- 内容点赞和取消点赞。
- 评论点赞和取消点赞。
- 收藏和取消收藏。
- 浏览量统计。
- 举报内容或用户。

## 6. Skills Hub

Skills Hub 用于发布和分享 Skill。

### 6.1 Skill 信息字段

- 名称和简短描述。
- 作者信息。
- 开源仓库，可选。
- ZIP 资源包。
- 文件大小。
- 浏览量、下载量。

Skill 以 ZIP 资源包形式上传，包含 `SKILL.md` 以及可选的 `references`、`scripts`、`assets` 等目录。

## 7. MCP Hub

MCP Hub 用于发布和分享 MCP Server。

### 7.1 MCP Server 信息字段

- 名称和简短描述。
- MCP Tools 清单。
- 安装方式和启动命令。
- 配置示例及环境变量说明。
- 作者信息。
- 源码仓库，可选。
- ZIP 资源包，可选。
- 浏览量、下载量。

## 8. 资源公共功能与审核

以下公共功能和审核规则同时适用于 Skills Hub 和 MCP Hub。

### 8.1 公共功能

- 分页浏览资源。
- 按标签筛选。
- 关键词搜索。
- 最新、热门和下载量排序。
- 资源详情展示。
- 发布、编辑和下架自己的资源。
- 点赞、收藏、评论和举报。
- 浏览量和下载量统计。
- 查看自己发布和收藏的资源。
- 管理员审核、置顶和下架资源。

### 8.2 资源审核

资源状态包括：

- 草稿。
- 待审核。
- 已发布。
- 已拒绝。
- 已下架。
- 已删除。

Skill 和 MCP Server 必须经过管理员审核后才能公开展示和下载。资源更新涉及新文件时，需要重新审核。

## 9. 平台 MCP Server

AIDevClub 提供整站 MCP Server，使 Codex、Claude Code 等 MCP 客户端能够访问平台。

MCP Server 与 Web REST API 共用同一套业务服务、权限规则和数据，不重复实现业务逻辑。

### 9.1 技术内容能力

- 搜索和读取文章。
- 获取最新和热门内容。
- 获取分类和标签。
- 发布、修改和删除自己的内容。
- 获取和发表评论。

### 9.2 AI 资源能力

- 搜索和读取 Skill、MCP Server。
- 获取资源使用文档和下载信息。
- 获取 MCP Server 的 Tools 和连接配置。
- 发布和修改自己的资源。
- 查询自己发布的资源。

### 9.3 用户能力

- 获取和修改个人资料。
- 获取自己发布、收藏的内容。
- 获取站内通知并标记已读。
- 点赞、收藏和举报内容。

## 10. 分类、标签与搜索

### 10.1 分类和标签

- 技术文章使用独立分类体系。
- Skill 和 MCP Server 不设分类，主要通过标签组织。
- 一条内容可以关联多个标签。
- 标签统一管理，文章、Skill 和 MCP Server 共用同一套标签。
- 管理员创建、禁用和合并标签。
- 普通用户优先从已有标签中选择。
- 记录标签使用次数并展示热门标签。

### 10.2 搜索和排行

- 搜索文章、Skill 和 MCP Server。
- 支持关键词、类型、分类和标签组合筛选。
- 搜索结果分页。
- 最新内容排行。
- 热门文章排行。
- 热门 Skill 和 MCP Server 排行。
- AI 资源下载排行。
- Redis 缓存热门排行结果。

## 11. 消息通知

- 文章收到评论。
- 评论收到回复。
- 内容或资源收到点赞。
- AI 资源审核通过或拒绝。
- 举报处理结果。
- 系统公告。
- 未读消息数量。
- 单条或全部标记已读。

通知采用站内通知。

## 12. 举报与审核

- 举报文章、评论、AI 资源或用户。
- 记录举报原因、说明、举报对象和处理状态。
- 管理员查看和处理举报。
- 隐藏、恢复或删除违规内容。
- 下架或恢复 AI 资源。
- 禁言、限制发布、封禁或解封用户。
- 将处理结果通知举报人和内容作者。
- 记录管理员关键操作。

## 13. 管理后台

- 用户查询、状态和角色管理。
- 文章和评论管理。
- Skill 和 MCP Server 审核管理。
- 分类和标签管理。
- 举报处理。
- 置顶、隐藏、下架和恢复内容。
- 管理员操作日志。
- 用户、内容、资源、下载和待审核数据统计。

## 14. 文件管理

- 用户头像上传。
- 文章正文图片上传。
- Skill ZIP 上传。
- MCP Server ZIP 上传。
- 未审核或已下架资源禁止公开下载。

## 15. 技术架构

- 后端：Go、Gin、GORM。
- 数据库：MySQL 8。
- 缓存与限流：Redis。
- 前端：Vue 3、TypeScript、Vite。
- 网关：Nginx。
- 部署：Docker、Docker Compose。
- 接口：REST API、MCP Server。

整体采用模块化单体架构。REST API 和 MCP Server 共享领域服务，通过 MySQL 持久化业务数据，Redis 负责缓存、限流、Token 状态和热门排行。

## 16. 核心业务流程

### 16.1 技术社区

```text
注册登录 → 发布文章 → 评论回复 → 点赞收藏 → 接收通知
```

### 16.2 Skills Hub 与 MCP Hub

```text
发布 Skill/MCP Server → 管理员审核 → 公开展示 → 下载和互动
```

### 16.3 MCP 客户端

```text
创建 API Token → 配置 MCP 客户端 → 搜索或读取内容 → 授权执行写操作 → 记录审计日志
```
